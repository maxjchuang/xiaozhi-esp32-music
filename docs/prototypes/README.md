# EchoEar Phase Four 浏览器视觉基准

使用浏览器打开 `character-phase-four.html`。单文件，无第三方依赖。

## 当前范围

- 11 个动作：挥爪、托腮、揉眼睛、吹泡泡、比心、捉小鱼、躲猫猫、沙锤、小鼓、小琴、吉他。
- 竖直胶囊眼；开心弯眼；侧头时双眼联动；B 短圆猫爪。
- 吉他收腰加宽，扫弦爪尖斜向右上，跨弦扫过后抬回。
- 空闲调度：关闭／安静／活泼，随机间隔、不连续重复、忙碌互斥、无互动后困倦。
- 陪听模拟：60 秒静音时间轴；四种乐器；猫咪与封面占位互斥显示。

这些是浏览器原型，不是固件功能。没有真实歌曲、歌词、节拍检测、语音工具或设备在场检测。
10 分钟无互动后的困倦只作用于表情，不等于硬件休眠或关机。
显示模式和活跃程度仅为页面内设置，不持久化。

## 手工验收

1. 逐一点击 11 个动作；揉眼结束进入困倦，其余返回待机。
2. 各动作中点“模拟打断”，确认立即切入聆听，无道具残留。
3. 空闲调度选择活泼＋加速预览，再点待机：首次约 3–6 秒触发；点击圆屏打断。
4. 检查后台暂停、音乐忙碌阻止自动动作、不连续重复。
5. 开始模拟播放，切换四种乐器及封面；检查不交叉显示、不重置播放计时。
6. 检查手动停止、圆屏打断及 60 秒自然结束。
