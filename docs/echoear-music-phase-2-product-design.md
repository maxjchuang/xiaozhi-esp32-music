# EchoEar 第二阶段：沉浸式音乐界面产品设计

## 目标

播放由外部音乐 MCP 解析的歌曲时，EchoEar 进入独立音乐场景：保留快速开播，同时呈现歌名、歌手、封面唱片与同步歌词。语音交互状态优先于音乐视觉，唤醒、聆听、思考、说话和错误均可立即覆盖音乐场景。

## 界面

- 360 × 360 暗化、轻微模糊的静态封面作为背景。
- 中央 192 × 192 圆形唱片，以每秒 5 帧、约 30 秒一圈缓慢旋转。
- 顶部居中显示歌名和歌手。
- 底部居中显示上一句、当前句、下一句歌词；当前句使用高亮色。
- 最底部显示播放进度。

## 降级规则

- 音频优先开播，元数据异步加载。
- 没有封面或处理失败时继续显示深色主题和默认唱片。
- 没有歌词时显示“暂无歌词”。
- 旧 MCP 只提供音频 URL 时仍可正常播放，并使用降级音乐场景。
- 本阶段不增加触摸播放控制。

## 中断与恢复

音乐场景只在设备空闲且音乐仍在播放时完整显示。进入唤醒、聆听、思考、说话或错误状态时，表情系统覆盖音乐界面；回到空闲后恢复当前音乐画面。歌曲结束、主动停止或播放失败后退出音乐场景，并由表情导演重新渲染实时状态。
